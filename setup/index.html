Set up your site

Start the setup helper to use this page. Double-click start-windows.bat (Windows) or start-mac.command (Mac), or run npm start in this folder. It opens this page at http://localhost:7470, where it can save your settings, scan your music and build the site. Needs Node.js from nodejs.org.

5. Music

Put your audio files in the music folder, then scan. File names become song titles; see the tips below.

File name tips
  • 0003 Who We Are.mp3: a leading number sets the order.
  • Night Drive B96PM.mp3 or 96BPM: the tempo.
  • Song 20251113.wav: a date (otherwise the file's date).
  • Song-404.mp3, Song-405.mp3: takes of one song, shown as versions.
  • Song ft Someone.mp3: featured artists.
  • DEMO 02 Song.mp3: track 2 of the album whose prefix is DEMO.

Albums

Songs whose file names start with the prefix go on the album. No cover? One is drawn for you.
