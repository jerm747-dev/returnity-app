Put your audio files here (mp3, wav, m4a, aac, flac, ogg, opus). Subfolders are fine.

Then press "Scan music" on the setup page (or run: npm run tracks) and build.
File name tips are on the setup page under Music.

This folder is copied to audio/ in the built site. It's left out of git (see .gitignore),
since music files are big; keep your masters backed up somewhere else.
