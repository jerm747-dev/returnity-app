HIGHWAY ENCORE — STANDALONE GAME WORKSHOP
Compatible v3 pair / Controller revision 4

Open index.html in this folder to launch the game directly.
The title screen has Start the run and How to play buttons.
Open controller.html for the enlarged, interactive controller study.
The study shows live input without starting a game.

KEYBOARD
Move with Left/Right or A/D.
Jump with Up, W, or Space. Hold to jump higher.
Duck with Down or S.
Hold Shift for speed.
X lifts a flipped road character or throws the one being carried.
P or Escape pauses and resumes.

TOUCH
Slide around the circular eight-way pad to change directions.
Up jumps. Down ducks. Left/Right move.
Upper diagonals jump and move; lower diagonals duck and move.
Both direction caps and the matching ring segment light up.
The center is neutral; releasing or leaving the pad clears its inputs.
The glossy action arc has Speed, Lift/Throw, and a larger Jump button.
Action names lead; smaller labels show Shift, X, and Space.
Speed toggles running. Direction and action buttons work together.
Keyboard and touch inputs can also be used simultaneously.

EDITING
index.html     Game markup, help dialog, HUD, and controller
style.css      Standalone shell, menus, and HUD
controls.css   Textures, reflections, thumb layout, and responsive sizing
controls-input.js  Eight-way hit detection and shared touch/keyboard input
controller.html   Standalone controller study and input monitor
interface.js   Game connection, sound, menus, and drawing loop
game.js        Level data, movement, collision, enemies, and pickups
cast.js        Drawn character artwork and animation
road.js        Scenery, roadway, and mansion
assets/        Required record icon

The playable demo has five road character types, breakable crates,
collectible notes, an eight-second Encore Disc, checkpoints, and a
mansion flag finish. Checkpoints are retained for the current run.
New runs and reloads reset progress. Sound is synthesized game effects.

For a paired installation, keep this folder named highway-encore under
the player page. The parent INSTALL-PAIR.txt explains that layout.
The player page's cast.js is the roster-preview snapshot. If the game
character drawing API stays compatible, copying an updated cast.js to
the player-page root also updates those preview portraits.

INSTALL THIS UPDATE
Extract into the same parent destination used for the compatible v3 pair.
Allow the highway-encore files to be replaced. The ZIP retains the
Returnity-Workshop-v3/highway-encore path so the existing player page
continues to open the game. The player-page design is unchanged.
If deploying manually, replace the entire highway-encore folder.
Refresh the browser after deployment; hard-refresh if old controls remain.
No build step, framework install, or external assets are required.
The controls are editable SVG/CSS; the reference photos are not bundled.

This revision supports keyboard and touch/pointer controls.
Physical gamepad input is not implemented.
